## Cost protection

Browser Run includes **10 minutes per day** on Cloudflare Workers Free; operations fail above free quota instead of silently enabling a paid subscription. Thumbnail Browser Run is on-demand, not hourly, so the hourly discovery has no rendering fees. All other ongoing tasks use Workers/D1 free quotas and YouTube Data API. Cloudflare billing endpoint access is not available to this connector, so no claim is made about an account-specific paid subscription or future invoice. Do not upgrade, add card details, use paid AI models or alter the old Shorts account. Use <https://developers.cloudflare.com/browser-run/pricing/> to check the latest official quotas.

## Testing and fail-safe policy

- All protected routes require an owner admin session. Forms use CSRF protection. OAuth refresh tokens stay encrypted with AES-GCM in D1.
- D1 drafts use ID-based idempotency; the first scan establishes a baseline and does not create retroactive drafts.
- Per-video approval records editor choice and review time. The writer additionally verifies OAuth channel ownership, privacy = private, duration ≥4 minutes, and title freshness.
- The writer renders a valid JPG **before** any YouTube write; duplicate attempts are denied via `optimizer_apply_log` and a partial failure is not silently retried.
- Public `/health` confirms `edits_enabled=false`, `uploads_enabled=false`, `publication_enabled=false`.
